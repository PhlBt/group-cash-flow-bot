# MessageService - Сервис отправки сообщений

## Назначение и архитектура сервиса

MessageService - класс, отвечающий за формирование и отправку всех сообщений пользователям в Telegram боте CashFlow. Сервис:

- Инкапсулирует всю работу с Telegram Bot API для отправки сообщений
- Форматирует данные для отображения пользователю
- Управляет inline клавиатурами
- Обеспечивает единообразие стиля сообщений

Архитектурно сервис:
- Принимает экземпляр Telegram Bot в конструкторе
- Предоставляет методы для всех типов сообщений
- Использует утилиты форматирования из utils/index.js
- Возвращает Promise для всех асинхронных операций

### sendCombinedRollMovePaydayMessage(chatId, player, steps, newPosition, fieldType, inFastTrack, paydayEvents)
- **Назначение**: Отправляет комбинированное сообщение с результатом броска кубика, перемещением игрока, финансовыми изменениями и информацией о следующем ходе
- **Параметры**:
  - `chatId` (number): ID чата
  - `player` (Object): Объект игрока
  - `steps` (number): Количество шагов (выпавшие очки)
  - `newPosition` (number): Новая позиция игрока (1-индексированная)
  - `fieldType` (string): Тип поля, на которое попал игрок
  - `inFastTrack` (boolean): Флаг нахождения на скоростной дорожке
  - `paydayEvents` (Array): Массив объектов выплат {cashFlow: number, ...} за пройденные поля PAYDAY
- **Функционал**:
  - Показывает результат броска кубика: "🎲 Профессия игрока выкинул X шагов"
  - Информирует о новой позиции: "📍 Трек, поле Y"
  - Суммирует и отображает все выплаты за поля PAYDAY: "💰 День выплат! Получено/Уплачено: сумма тыс ₽"
  - Показывает тип поля назначения: "📍 Название поля"
  - Отображает обновленный баланс игрока после всех выплат
  - Показывает текущие финансовые показатели: пассивный доход, общие расходы, денежный поток
  - Предоставляет inline клавиатуру с кнопками действий для следующего хода

### sendCombinedRollMoveDealMessage(chatId, player, steps, newPosition, inFastTrack, paydayEvents)
- **Назначение**: Отправляет комбинированное сообщение с броском, перемещением, выплатами и полем "Сделки"
- **Параметры**:
  - `chatId` (number): ID чата
  - `player` (Object): Объект игрока
  - `steps` (number): Количество шагов
  - `newPosition` (number): Новая позиция
  - `inFastTrack` (boolean): На Fast Track
  - `paydayEvents` (Array): Массив событий выплат
- **Функционал**:
  - Показывает результат броска кубика и перемещение
  - Суммирует выплаты за поля PAYDAY
  - Показывает информацию о попадании на поле "Сделки"
  - Отображает текущий баланс и финансовые показатели
  - Предоставляет клавиатуру dealTypeKeyboard для выбора типа сделки

### sendDealTypeMessage(chatId)
- **Назначение**: Отправляет сообщение выбора типа сделки
- **Параметры**:
  - `chatId` (number): ID чата
- **Возвращает**: Promise<number> - ID отправленного сообщения
- **Функционал**:
  - Отправляет сообщение "💼 Вы попали на поле 'Сделки'! Выберите тип сделки:"
  - Предоставляет клавиатуру dealTypeKeyboard с кнопками "Мелкая сделка" и "Крупная сделка"

### sendDealCardMessage(chatId, deal, player)
- **Назначение**: Отправляет карточку инвестиционной сделки
- **Параметры**:
  - `chatId` (number): ID чата
  - `deal` (Object): Объект сделки с расширенными полями (cost, passiveIncome, roi, sellRange, range, downPayment, mortgage, apartments, description, title)
  - `player` (Object): Объект игрока для отображения баланса
- **Возвращает**: Promise<number> - ID отправленного сообщения
- **Функционал**:
  - Форматирует карточку сделки в Markdown: название, описание, стоимость, доход
  - Показывает текущий баланс игрока (поле "Ваши деньги")
  - Отображает дополнительные параметры сделки:
    - Стоимость (cost)
    - Пассивный доход (passiveIncome или cashFlow)
    - Процент доходности (roi)
    - Диапазон продажи (sellRange)
    - Диапазон цен (range)
    - Первоначальный взнос (downPayment)
    - Ипотека (mortgage)
    - Количество квартир (apartments)
  - Показывает стоимость покупки кредитной картой (2% от стоимости, если указана)
  - Предоставляет динамическую клавиатуру через generateDealKeyboard() с кнопками ("Купить", "Пропустить", "Предложить игроку" - если применимо)

## Зависимости

- **Telegram Bot API**: Для отправки сообщений
- **keyboards.js**: Для inline клавиатур (generateDealKeyboard, статические клавиатуры)
- **utils/index.js**: Для форматирования чисел

## Архитектурные принципы

- **Единственная ответственность**: MessageService отвечает только за сообщения
- **Форматирование**: Все числа форматируются через formatNumber()
- **Клавиатуры**: Использует предопределенные клавиатуры из keyboards.js
- **Обработка ошибок**: Безопасно обрабатывает ошибки API
- **Асинхронность**: Все методы возвращают Promise
