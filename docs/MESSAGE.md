# MessageService - Сервис отправки сообщений

## Назначение и архитектура сервиса

MessageService - класс, отвечающий за формирование и отправку всех сообщений пользователям в Telegram боте CashFlow. Сервис:

- Инкапсулирует всю работу с Telegram Bot API для отправки сообщений
- Форматирует данные для отображения пользователю
- Управляет inline клавиатурами
- Обеспечивает единообразие стиля сообщений

Архитектурно сервис:
- Принимает экземпляр Telegram Bot в конструкторе
- Предоставляет методы для всех типов сообщений
- Использует утилиты форматирования из utils/index.js
- Возвращает Promise для всех асинхронных операций

## Методы с их функционалом

### sendWelcomeMessage(chatId, userName)
- **Назначение**: Отправляет приветственное сообщение
- **Параметры**:
  - `chatId` (number): ID чата
  - `userName` (string): Имя пользователя
- **Функционал**: Отправляет сообщение с кнопками welcomeKeyboard

### sendHelpMessage(chatId)
- **Назначение**: Отправляет справочное сообщение
- **Параметры**:
  - `chatId` (number): ID чата
- **Функционал**: Отправляет форматированное сообщение со списком команд

### sendRulesMessage(chatId)
- **Назначение**: Отправляет правила игры
- **Параметры**:
  - `chatId` (number): ID чата
- **Функционал**: Отправляет подробные правила в Markdown формате

### sendGameCreatedMessage(chatId, gameId)
- **Назначение**: Сообщает о создании новой игры
- **Параметры**:
  - `chatId` (number): ID чата
  - `gameId` (string): ID игры
- **Функционал**: Информирует пользователя об ID созданной игры

### sendGameCreationErrorMessage(chatId)
- **Назначение**: Сообщает об ошибке создания игры
- **Параметры**:
  - `chatId` (number): ID чата
- **Функционал**: Отправляет сообщение об ошибке

### sendJoinSuccessMessage(chatId, gameId)
- **Назначение**: Сообщает об успешном присоединении к игре
- **Параметры**:
  - `chatId` (number): ID чата
  - `gameId` (string): ID игры
- **Функционал**: Подтверждает присоединение к игре

### sendJoinErrorMessage(chatId, errorType)
- **Назначение**: Сообщает об ошибке присоединения
- **Параметры**:
  - `chatId` (number): ID чата
  - `errorType` (string): Тип ошибки ('not_found', 'already_joined', 'game_started')
- **Функционал**: Отправляет специфическое сообщение об ошибке

### sendPlaySuccessMessage(chatId, gameId)
- **Назначение**: Сообщает об успешном начале игры
- **Параметры**:
  - `chatId` (number): ID чата
  - `gameId` (string): ID игры
- **Функционал**: Подтверждает начало игры

### sendPlayErrorMessage(chatId, errorType)
- **Назначение**: Сообщает об ошибке начала игры
- **Параметры**:
  - `chatId` (number): ID чата
  - `errorType` (string): Тип ошибки ('not_found', 'not_creator', 'already_started')
- **Функционал**: Отправляет специфическое сообщение об ошибке

### sendPlayerCard(chatId, player)
- **Назначение**: Отправляет карточку игрока
- **Параметры**:
  - `chatId` (number): ID чата
  - `player` (Object): Объект игрока
- **Функционал**: Форматирует и отправляет полную информацию об игроке

### sendEndGameVoteMessage(chatId, game, votedUsers)
- **Назначение**: Отправляет сообщение голосования за окончание игры
- **Параметры**:
  - `chatId` (number): ID чата
  - `game` (Object): Объект игры
  - `votedUsers` (Array): Массив ID проголосовавших
- **Возвращает**: Promise<number> - ID отправленного сообщения
- **Функционал**: Создает сообщение с кнопкой голосования и списком голосов

### updateEndGameVoteMessage(chatId, messageId, game, votedUsers)
- **Назначение**: Обновляет сообщение голосования
- **Параметры**:
  - `chatId` (number): ID чата
  - `messageId` (number): ID сообщения для обновления
  - `game` (Object): Объект игры
  - `votedUsers` (Array): Массив ID проголосовавших
- **Функционал**: Редактирует существующее сообщение голосования

### sendGameFinishedMessage(chatId, gameId)
- **Назначение**: Сообщает о завершении игры
- **Параметры**:
  - `chatId` (number): ID чата
  - `gameId` (string): ID игры
- **Функционал**: Информирует о завершении игры

### sendEndGameErrorMessage(chatId, errorType)
- **Назначение**: Сообщает об ошибке окончания игры
- **Параметры**:
  - `chatId` (number): ID чата
  - `errorType` (string): Тип ошибки
- **Функционал**: Отправляет специфическое сообщение об ошибке

### sendWaitingRoomMessage(chatId, game)
- **Назначение**: Отправляет сообщение комнаты ожидания
- **Параметры**:
  - `chatId` (number): ID чата
  - `game` (Object): Объект игры
- **Возвращает**: Promise<number> - ID отправленного сообщения
- **Функционал**: Показывает список игроков в ожидании

### deleteMessage(chatId, messageId)
- **Назначение**: Удаляет сообщение
- **Параметры**:
  - `chatId` (number): ID чата
  - `messageId` (number): ID сообщения
- **Функционал**: Безопасно удаляет сообщение (игнорирует ошибки)

### sendErrorMessage(chatId, errorText)
- **Назначение**: Отправляет общее сообщение об ошибке
- **Параметры**:
  - `chatId` (number): ID чата
  - `errorText` (string): Текст ошибки
- **Функционал**: Отправляет текст ошибки пользователю

### sendPlayerTurnMessage(chatId, player)
- **Назначение**: Отправляет сообщение о ходе игрока
- **Параметры**:
  - `chatId` (number): ID чата
  - `player` (Object): Объект игрока
- **Возвращает**: Promise<number> - ID отправленного сообщения
- **Функционал**: Показывает информацию о текущем игроке и предлагает действия

### sendDiceRollMessage(chatId, diceCount, totalSteps)
- **Назначение**: Отправляет результат броска кубика
- **Параметры**:
  - `chatId` (number): ID чата
  - `diceCount` (number): Количество кубиков
  - `totalSteps` (number): Сумма очков
- **Функционал**: Показывает эмодзи кубиков и результат

### sendMoveMessage(chatId, player, oldPosition, newPosition, fieldType, inFastTrack)
- **Назначение**: Отправляет сообщение о перемещении игрока
- **Параметры**:
  - `chatId` (number): ID чата
  - `player` (Object): Объект игрока
  - `oldPosition` (number): Старая позиция
  - `newPosition` (number): Новая позиция
  - `fieldType` (string): Тип поля
  - `inFastTrack` (boolean): На Fast Track
- **Функционал**: Информирует о перемещении и типе поля

### getDiceEmoji(value)
- **Назначение**: Возвращает эмодзи для грани кубика
- **Параметры**:
  - `value` (number): Значение (1-6)
- **Возвращает**: string - Эмодзи кубика
- **Функционал**: Преобразует число в соответствующий эмодзи

### getFieldName(fieldType)
- **Назначение**: Возвращает название типа поля
- **Параметры**:
  - `fieldType` (string): Тип поля
- **Возвращает**: string - Название поля
- **Функционал**: Преобразует тип поля в читаемое название

## Зависимости

- **Telegram Bot API**: Для отправки сообщений
- **keyboards.js**: Для inline клавиатур
- **utils/index.js**: Для форматирования чисел

## Архитектурные принципы

- **Единственная ответственность**: MessageService отвечает только за сообщения
- **Форматирование**: Все числа форматируются через formatNumber()
- **Клавиатуры**: Использует предопределенные клавиатуры из keyboards.js
- **Обработка ошибок**: Безопасно обрабатывает ошибки API
- **Асинхронность**: Все методы возвращают Promise
