# Модуль сделок - Deals Module

## Назначение и архитектура модуля

Модуль сделок отвечает за генерацию случайных инвестиционных возможностей в игре Cash Flow. Состоит из трех основных компонентов:

- **smallDeals.js** (`src/game/cards/smallDeals.js`) - массив мелких сделок с расширенными параметрами
- **bigDeals.js** (`src/game/cards/bigDeals.js`) - массив крупных сделок с расширенными параметрами
- **deals.js** (`src/game/deals.js`) - генераторы сделок и вспомогательные функции

Модуль предоставляет:
- Генерацию мелких сделок с богатыми параметрами
- Генерацию крупных сделок с расчетом кредитования
- Случайный выбор из предопределенных массивов
- Расчет финансовых параметров сделок

Архитектурно модуль:
- Экспортирует функции генерации из разных файлов
- Содержит статические массивы предопределенных сделок
- Возвращает объекты сделок со всеми необходимыми полями
- Не зависит от других модулей игры

## Структура мелкой сделки (smallDeals)

Мелкие сделки из `smallDeals.js` имеют расширенную структуру:

```javascript
{
  id: "small_deal_0",           // Уникальный идентификатор
  type: "small",                // Тип сделки
  title: "string",              // Название сделки
  description: "string",        // Подробное описание
  cost: number,                 // Стоимость в рублях (может отсутствовать)
  passiveIncome: number,        // Пассивный доход в рублях (может отсутствовать)
  roi: "string",                // Процент доходности (например, "38%")
  sellRange: "string",          // Диапазон продажи (например, "1.4 млн ₽ - 1.9 млн ₽")
  range: "string",              // Диапазон цен для акций (например, "150 ₽ - 1 200 ₽")
  downPayment: number,          // Первоначальный взнос (может отсутствовать)
  mortgage: number,             // Ипотечный кредит (может отсутствовать)
  canSellToOthers: boolean,     // Можно ли предлагать другим игрокам
  unlimitedStocks: boolean,     // Неограниченное количество акций
  canSellStocks: boolean,       // Можно ли продавать акции
  multiple: number,             // Множитель для акций (увеличение/уменьшение)
  anyCanBuySell: boolean        // Любой игрок может покупать/продавать
}
```

## Структура крупной сделки (bigDeals)

Крупные сделки из `bigDeals.js` имеют расширенную структуру:

```javascript
{
  id: "big_deal_0",             // Уникальный идентификатор
  type: "big",                  // Тип сделки
  title: "string",              // Название сделки
  description: "string",        // Подробное описание
  cost: number,                 // Стоимость в рублях
  passiveIncome: number,        // Пассивный доход в рублях (месячный)
  mortgage: number,             // Сумма ипотечного кредита
  downPayment: number,          // Первоначальный взнос
  roi: "string",                // Процент доходности (например, "48% КОИ")
  sellRange: "string",          // Диапазон продажи (например, "1.5 млн ₽ - 2.4 млн ₽")
  canSellToOthers: boolean,     // Можно ли предлагать другим игрокам
  apartments: number            // Количество квартир (для жилых комплексов)
}
```

## Информация на карточке сделки

Карточка сделки отображает следующую информацию для принятия решения:

- **Название и описание** сделки
- **Стоимость** (если указана)
- **Денежный поток/пассивный доход** (ежемесячный доход)
- **Процент доходности** (ROI)
- **Диапазон продажи** (для недвижимости)
- **Диапазон цен** (для акций)
- **Первоначальный взнос** (если указан)
- **Ипотека** (если указана)
- **Ваши деньги** - текущий баланс игрока
- **Стоимость кредитной карты** - 2% от стоимости (альтернативный способ оплаты)

## Функции генерации

### getRandomSmallDeal()
- **Расположение**: `src/game/cards/smallDeals.js`
- **Назначение**: Генерирует случайную мелкую сделку
- **Параметры**: Нет
- **Возвращает**: Object - объект мелкой сделки
- **Функционал**:
  - Выбирает случайную сделку из массива smallDeals
  - Возвращает объект с типом "small"
  - Сделки включают недвижимость, акции, бизнесы, депозиты, монеты

### generateBigDeal()
- **Расположение**: `src/game/deals.js`
- **Назначение**: Генерирует случайную крупную сделку
- **Параметры**: Нет
- **Возвращает**: Object - объект крупной сделки
- **Функционал**:
  - Выбирает случайную сделку из массива bigDeals (src/game/cards/bigDeals.js)
  - Возвращает объект с расширенными полями (passiveIncome, mortgage, downPayment, roi, sellRange, apartments)
  - Сделки включают крупную недвижимость, бизнесы, инвестиционные проекты

## Типы мелких сделок

Мелкие сделки включают различные категории активов:

- **Недвижимость**: Квартиры, дома с указанием ROI и диапазона продажи
- **Акции**: Компаний с диапазоном цен и возможностью неограниченной покупки
- **Депозиты**: Банковские сертификаты с гарантированным доходом
- **Бизнес**: Создание компаний, франшизы
- **Золото**: Монеты с диапазоном цен продажи
- **Специальные**: Кредиты, страховки, другие финансовые инструменты

## Правила игры для сделок

### Мелкие сделки
- **Стоимость**: Полная оплата наличными (если указана)
- **Условие покупки**: `player.cash >= deal.cost` (если cost указан)
- **Результат**: Добавление актива, увеличение пассивного дохода
- **Дополнительные параметры**: Отображаются на карточке для информации

### Крупные сделки
- **Первоначальный взнос**: Используется значение из `downPayment` сделки
- **Кредит**: Используется значение из `mortgage` сделки
- **Ежемесячный платеж**: 0.01% от стоимости сделки
- **Условие покупки**: `player.cash >= deal.downPayment`
- **Результат**: Добавление актива + кредита, увеличение пассивного дохода и расходов



## Интеграция с игрой

Модуль сделок используется в следующих сценариях:
- **Поле "Сделки"**: При попадании на поле DEAL
- **Выбор типа**: Игрок выбирает мелкую или крупную сделку
- **Показ карточки**: Отображение деталей сделки с кнопками действий
- **Покупка**: Финансовая транзакция и обновление состояния игрока
- **Пропуск**: Переход хода следующему игроку

## Архитектурные принципы

- **Изоляция данных**: Сделки генерируются независимо от состояния игры
- **Предопределенность**: Все возможные сделки описаны в коде
- **Случайность**: Равномерное распределение при выборе сделок
- **Расширяемость**: Легко добавить новые сделки в массивы
- **Читаемость**: Ясная структура объектов сделок
- **Информационная полнота**: Карточки содержат все необходимые данные для принятия решений
