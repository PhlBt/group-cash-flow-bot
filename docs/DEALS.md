# Модуль сделок - Deals Module

## Назначение и архитектура модуля

Модуль сделок (`src/game/deals.js`) отвечает за генерацию случайных инвестиционных возможностей в игре Cash Flow. Модуль предоставляет:

- Генерацию мелких сделок (small deals) - недорогие активы с умеренным доходом
- Генерацию крупных сделок (big deals) - дорогие активы с высоким доходом, но требующие кредитования
- Случайный выбор из предопределенных массивов сделок
- Расчет финансовых параметров сделок

Архитектурно модуль:
- Экспортирует две основные функции генерации
- Содержит статические массивы предопределенных сделок
- Возвращает объекты сделок со всеми необходимыми полями
- Не зависит от других модулей игры

## Структура сделки

```javascript
{
  type: "small|big",           // Тип сделки
  title: "string",             // Название сделки
  cost: number,                // Стоимость в рублях
  cashFlow: number,            // Месячный денежный поток в рублях
  description: "string",       // Описание сделки
  downPayment?: number         // Первоначальный взнос (только для big deals, 20% от стоимости)
}
```

## Информация на карточке сделки

Карточка сделки отображает следующую информацию для принятия решения:

- **Название и описание** сделки
- **Стоимость** сделки
- **Денежный поток** (ежемесячный доход)
- **Ваши деньги** - текущий баланс игрока
- **Стоимость кредитной карты** - 0.02% от стоимости сделки (альтернативный способ оплаты)
- **Для крупных сделок**:
  - Первоначальный взнос (20% от стоимости)
  - Сумма кредита
  - Ежемесячный платеж по кредиту (0.01% от стоимости)

## Функции генерации

### generateSmallDeal()
- **Назначение**: Генерирует случайную мелкую сделку
- **Параметры**: Нет
- **Возвращает**: Object - объект мелкой сделки
- **Функционал**:
  - Выбирает случайную сделку из массива smallDeals
  - Возвращает объект с типом "small"
  - Сделки включают франшизы, акции, недвижимость, бизнесы

### generateBigDeal()
- **Назначение**: Генерирует случайную крупную сделку
- **Параметры**: Нет
- **Возвращает**: Object - объект крупной сделки
- **Функционал**:
  - Выбирает случайную сделку из массива bigDeals
  - Автоматически рассчитывает первоначальный взнос (20% от стоимости)
  - Возвращает объект с типом "big"
  - Сделки включают крупную недвижимость, бизнесы, инвестиционные проекты

## Правила игры для сделок

### Мелкие сделки
- **Стоимость**: Полная оплата наличными
- **Условие покупки**: `player.cash >= deal.cost`
- **Результат**: Добавление актива, увеличение пассивного дохода

### Крупные сделки
- **Первоначальный взнос**: 20% от стоимости
- **Кредит**: 80% от стоимости
- **Ежемесячный платеж**: 0.01% от стоимости сделки
- **Условие покупки**: `player.cash >= deal.downPayment`
- **Результат**: Добавление актива + кредита, увеличение пассивного дохода и расходов

## Интеграция с игрой

Модуль сделок используется в следующих сценариях:
- **Поле "Сделки"**: При попадании на поле DEAL
- **Выбор типа**: Игрок выбирает мелкую или крупную сделку
- **Показ карточки**: Отображение деталей сделки с кнопками действий
- **Покупка**: Финансовая транзакция и обновление состояния игрока
- **Пропуск**: Переход хода следующему игроку

## Архитектурные принципы

- **Изоляция данных**: Сделки генерируются независимо от состояния игры
- **Предопределенность**: Все возможные сделки описаны в коде
- **Случайность**: Равномерное распределение при выборе сделок
- **Расширяемость**: Легко добавить новые сделки в массивы
- **Читаемость**: Ясная структура объектов сделок
