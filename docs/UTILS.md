# Utils - Утилиты

## Назначение и архитектура модуля

Utils - модуль вспомогательных функций и утилит для Telegram бота CashFlow. Содержит общие функции форматирования, валидации, циркуляции и другие полезные утилиты.

Архитектурно модуль состоит из нескольких файлов:
- **index.js**: Главный экспорт всех утилит и часто используемых функций
- **validators.js**: Функции валидации данных и проверок
- **dealCirculation.js**: Утилиты для циркуляции сделок между игроками
- **dealOffer.js**: Утилиты для управления предложениями сделок
- **rateLimiter.js**: Ограничение скорости отправки сообщений
- **keyboards.js**: Генерация inline клавиатур для бота
- **formatters.js**: Форматирование чисел и текста

## index.js - Главный экспорт утилит

### formatNumber(num)
- **Назначение**: Форматирует число с разделителями разрядов или краткими формами
- **Параметры**:
  - `num` (number): Число для форматирования
- **Возвращает**: string - Отформатированное число с ₽
- **Функционал**:
  - Для чисел >= 1 млн: показывается как "X.X млн"
  - Для круглых тысяч >= 1000: показывается как "X тыс"
  - Для остальных чисел: добавляются пробелы-разделители разрядов
  - Всегда добавляется символ ₽

### RateLimiter (класс)
- **Назначение**: Класс для ограничения скорости отправки сообщений
- **Экспорт**: Из rateLimiter.js
- **Функционал**: Реализует глобальные и чат-специфичные лимиты отправки сообщений

### dealCirculation утилиты
- **initializeDealCirculation**: Инициализация циркуляции сделок
- **processDealAction**: Обработка действия игрока в циркуляции
- **circulateToNextPlayer**: Переход к следующему игроку
- **endDealCirculation**: Завершение циркуляции
- **initializeCanSellStocksCirculation**: Инициализация циркуляции для продажи акций
- **processCanSellStocksAction**: Обработка продажи акций в циркуляции

## validators.js - Валидация данных

### validateCurrentPlayer(gameId, userId, services, chatId)
- **Назначение**: Проверяет, является ли пользователь текущим игроком
- **Параметры**:
  - `gameId` (string): ID игры
  - `userId` (string): ID пользователя
  - `services` (Object): Объект с сервисами { gameService, messageService }
  - `chatId` (number): ID чата для отправки сообщений об ошибках
- **Возвращает**: Promise<Object|null> - объект игрока или null при ошибке
- **Функционал**:
  - Получает текущего игрока через gameService.getCurrentPlayer()
  - Проверяет совпадение userId
  - При несоответствии отправляет сообщение об ошибке и возвращает null

## dealCirculation.js - Циркуляция сделок

### initializeDealCirculation(game, currentDeal, services)
- **Назначение**: Инициализация циркуляции anyCanBuySell сделки между игроками
- **Параметры**:
  - `game` (Object): Объект игры
  - `currentDeal` (Object): Текущая сделка
  - `services` (Object): Объект с сервисами
- **Возвращает**: Promise<Array> - массив ID игроков для циркуляции
- **Функционал**:
  - Находит игроков с активами соответствующей группы (group_Id)
  - Устанавливает порядок циркуляции начиная с текущего игрока
  - Сохраняет данные циркуляции в базе данных

### processDealAction(gameId, userId, action, services)
- **Назначение**: Обрабатывает действие игрока в циркуляции сделки
- **Параметры**:
  - `gameId` (string): ID игры
  - `userId` (string): ID игрока
  - `action` (string): Действие ('buy', 'skip', 'sell_stocks')
  - `services` (Object): Объект с сервисами
- **Возвращает**: Promise<Object> - результат действия
- **Функционал**:
  - Выполняет соответствующее действие (покупка, продажа, пропуск)
  - Переходит к следующему игроку или завершает циркуляцию

### circulateToNextPlayer(gameId, services)
- **Назначение**: Передает циркуляцию следующему игроку
- **Параметры**:
  - `gameId` (string): ID игры
  - `services` (Object): Объект с сервисами
- **Возвращает**: Promise<void>
- **Функционал**:
  - Увеличивает индекс циркуляции
  - Показывает сделку следующему игроку или завершает циркуляцию

### endDealCirculation(gameId, services)
- **Назначение**: Завершает циркуляцию сделки
- **Параметры**:
  - `gameId` (string): ID игры
  - `services` (Object): Объект с сервисами
- **Возвращает**: Promise<void>
- **Функционал**:
  - Очищает данные циркуляции из базы данных
  - Передает ход следующему игроку

### initializeCanSellStocksCirculation(game, currentDeal, services)
- **Назначение**: Инициализация циркуляции для продажи акций
- **Параметры**:
  - `game` (Object): Объект игры
  - `currentDeal` (Object): Текущая сделка
  - `services` (Object): Объект с сервисами
- **Возвращает**: Promise<Array> - массив ID игроков
- **Функционал**:
  - Аналогично initializeDealCirculation, но для акций

### processCanSellStocksAction(gameId, userId, action, services)
- **Назначение**: Обрабатывает продажу акций в циркуляции
- **Параметры**:
  - `gameId` (string): ID игры
  - `userId` (string): ID игрока
  - `action` (string): Действие игрока
  - `services` (Object): Объект с сервисами
- **Возвращает**: Promise<Object> - результат
- **Функционал**:
  - Продает акции по текущей цене
  - Обновляет финансы игрока

## dealOffer.js - Предложения сделок

### OFFER_STATES
Константы состояний предложения сделок:
- `COMMISSION`: Выбор комиссии
- `SELECT_USER`: Выбор пользователя
- `CONFIRMED`: Предложение подтверждено

### initializeDealOffer(gameId, offeringUserId, services)
- **Назначение**: Инициализация предложения сделки другому игроку
- **Параметры**:
  - `gameId` (string): ID игры
  - `offeringUserId` (string): ID предлагающего игрока
  - `services` (Object): Объект с сервисами { gameService, messageService }
- **Возвращает**: Promise<void>
- **Функционал**:
  - Создает состояние предложения с шагом COMMISSION
  - Сохраняет в базе данных через databaseService.setOfferState()

### processOfferStep(gameId, userId, chatId, action, data, services)
- **Назначение**: Обработка шага предложения сделки
- **Параметры**:
  - `gameId` (string): ID игры
  - `userId` (string): ID игрока
  - `chatId` (string): ID чата
  - `action` (string): Действие ('select_commission', 'select_user', 'cancel')
  - `data` (Object): Данные действия
  - `services` (Object): Объект с сервисами { gameService, messageService }
- **Возвращает**: Promise<void>
- **Функционал**:
  - В зависимости от action вызывает соответствующий обработчик
  - Обрабатывает выбор комиссии, пользователя или отмену

### calculateDealWithCommission(deal, commission)
- **Назначение**: Рассчитывает стоимость сделки с комиссией
- **Параметры**:
  - `deal` (Object): Объект сделки
  - `commission` (number): Процент комиссии
- **Возвращает**: Object - сделка с новой стоимостью и комиссией
- **Функционал**:
  - Увеличивает стоимость на процент комиссии
  - Добавляет поля commission, originalCost, originalDownPayment

### calculateCommission(deal, commission)
- **Назначение**: Рассчитывает сумму комиссии
- **Параметры**:
  - `deal` (Object): Объект сделки
  - `commission` (number): Процент комиссии
- **Возвращает**: number - сумма комиссии
- **Функционал**:
  - Вычисляет комиссию от первоначального взноса или стоимости

### transferCommission(gameId, offeringUserId, commissionAmount, services)
- **Назначение**: Переводит комиссию предлагающему игроку
- **Параметры**:
  - `gameId` (string): ID игры
  - `offeringUserId` (string): ID получателя комиссии
  - `commissionAmount` (number): Сумма комиссии
  - `services` (Object): Объект с сервисами
- **Возвращает**: Promise<void>
- **Функционал**:
  - Начисляет комиссию через databaseService.updatePlayerCash()

### passTurnAfterOffer(game, offeringUserId, services)
- **Назначение**: Передает ход после предложения сделки
- **Параметры**:
  - `game` (Object): Объект игры
  - `offeringUserId` (string): ID предлагающего игрока
  - `services` (Object): Объект с сервисами { gameService, messageService }
- **Возвращает**: Promise<void>
- **Функционал**:
  - Находит индекс следующего игрока
  - Устанавливает текущего игрока и сбрасывает diceRolledThisTurn
  - Отправляет сообщение о ходе следующему игроку

## rateLimiter.js - Ограничение скорости

### RateLimiter класс
- **Свойства**:
  - `globalLimiter`: Bottleneck лимитер для всех сообщений (30 msg/sec)
  - `chatLimiters`: Map лимитеров для каждого чата (20 msg/min)
- **Методы**:
  - `schedule(chatId, operation)`: Планирует операцию с соблюдением лимитов
  - `cleanupUnusedLimiters()`: Очищает неиспользуемые лимитеры чатов
  - `stop()`: Останавливает все лимитеры

## keyboards.js - Клавиатуры

### waitingRoomKeyboard
- **Назначение**: Клавиатура комнаты ожидания
- **Функционал**: Кнопки "🎮 Присоединиться к игре", "📋 Правила игры", "❓ Помощь", "🚀 Начать игру"

### welcomeKeyboard
- **Назначение**: Приветственная клавиатура
- **Функционал**: Кнопки "🎮 Играть!", "📋 Правила игры", "❓ Помощь"

### dealTypeKeyboard
- **Назначение**: Выбор типа сделки
- **Функционал**: Кнопки "Мелкая сделка", "Крупная сделка"

### generateDealKeyboard(deal)
- **Назначение**: Динамическая клавиатура для карточки сделки
- **Параметры**:
  - `deal` (Object): Объект сделки
- **Функционал**:
  - Кнопки "Купить", "Пропустить"
  - При canSellToOthers добавляется "Предложить игроку"
  - В режиме предложения: кнопки выбора комиссии или игроков

### charityChoiceKeyboard
- **Назначение**: Выбор действия на поле благотворительности
- **Функционал**: Кнопки "🙏 Пожертвовать 10% дохода", "⏭️ Пропустить"

### generateMiscellaneousKeyboard(miscCard, player, canPay)
- **Назначение**: Клавиатура для miscellaneous карт
- **Параметры**:
  - `miscCard` (Object): Карточка miscellaneous
  - `player` (Object): Игрок
  - `canPay` (boolean): Возможность оплаты
- **Функционал**:
  - Для карт с кредитом: "Оплатить [сумма] ₽", "💳 Кредитная карта"
  - Для обычных карт: только "Оплатить [сумма] ₽"
  - При невозможности оплаты: "Пропустить"

## Архитектурные принципы

- **Модульность**: Каждый файл отвечает за свою область функциональности
- **Переиспользование**: Утилиты используются во многих частях приложения
- **Изоляция**: Утилиты не зависят от бизнес-логики сервисов
- **Производительность**: Оптимизированы для частого использования
- **Расширяемость**: Легко добавлять новые утилиты в соответствующие файлы
