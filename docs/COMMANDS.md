# Команды бота CashFlow

## Основные команды

### /start
- **Описание**: Запуск бота и приветствие пользователя
- **Использование**: `/start`
- **Ответ**: Приветственное сообщение с инструкцией использовать `/help`

### /help
- **Описание**: Показать список всех доступных команд
- **Использование**: `/help`
- **Ответ**: Форматированное сообщение со списком команд и описанием игры

### /newgame
- **Описание**: Создать новую игровую сессию
- **Использование**: `/newgame`
- **Ответ**: Сообщение с ID созданной игры, который можно передать другим игрокам

### /play [game_id]
- **Описание**: Начать игру
- **Использование**: `/play 1234567890` (где 1234567890 - ID игры)
- **Ответ**: Подтверждение начала игры или сообщение об ошибке

### /endgame
- **Описание**: Начать голосование за окончание игры
- **Использование**: `/endgame`
- **Ответ**: Сообщение с голосованием или сообщение об ошибке

## Inline кнопки

### Кнопки в сообщении /start
- **🎮 Играть!**: Создает новую игровую сессию для чата или присоединяется к существующей активной игре в чате. Первый нажавший создает игру, последующие присоединяются.
- **📋 Правила игры**: Показывает подробные правила игры
- **❓ Помощь**: Показывает список команд и справку (эквивалентно /help)
