# Команды бота CashFlow

## Основные команды

### /start
- **Описание**: Запуск бота и приветствие пользователя
- **Использование**: `/start`
- **Ответ**: Приветственное сообщение с инструкцией использовать `/help`

### /help
- **Описание**: Показать список всех доступных команд
- **Использование**: `/help`
- **Ответ**: Форматированное сообщение со списком команд и описанием игры

### /newgame
- **Описание**: Создать новую игровую сессию
- **Использование**: `/newgame`
- **Ответ**: Сообщение с ID созданной игры, который можно передать другим игрокам

### /join [game_id]
- **Описание**: Присоединиться к существующей игре
- **Использование**: `/join 1234567890` (где 1234567890 - ID игры)
- **Ответ**: Подтверждение присоединения к игре или сообщение об ошибке

## Статусы игры

- **waiting**: Игра ожидает дополнительных игроков
- **active**: Игра в процессе (пока не реализована)
- **finished**: Игра завершена (пока не реализована)

## Игровая механика

CashFlow - настольная игра о финансовом планировании. Основные концепции:
- Управление доходами и расходами
- Инвестирование в активы
- Стратегия выхода из "крысиных бегов"
- Финансовая независимость

Бот предоставляет базовую инфраструктуру для многопользовательских сессий. Полная игровая логика может быть расширена в будущем.
