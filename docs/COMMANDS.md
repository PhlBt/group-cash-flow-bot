# Команды бота CashFlow

## Основные команды

### /start
- **Описание**: Запуск бота и приветствие пользователя
- **Использование**: `/start`
- **Ответ**: Приветственное сообщение с инструкцией использовать `/help`

### /help
- **Описание**: Показать список всех доступных команд
- **Использование**: `/help`
- **Ответ**: Форматированное сообщение со списком команд и описанием игры

### /profile
- **Описание**: Показать профиль игрока с кнопками для просмотра активов и кредитов
- **Использование**: `/profile`
- **Ответ**: Сообщение с профилем игрока, статистикой и inline кнопками

### /leave
- **Описание**: Выйти из активной игры в чате
- **Использование**: `/leave`
- **Ответ**: Подтверждение выхода из игры или сообщение об ошибке

### /endgame
- **Описание**: Начать голосование за окончание игры в текущем чате (требуется активная игра пользователя в этом чате)
- **Использование**: `/endgame`
- **Ответ**: Сообщение с голосованием или сообщение об ошибке

### /rules
- **Описание**: Показать подробные правила игры CashFlow
- **Использование**: `/rules`
- **Ответ**: Сообщение с полными правилами игры

### /votekick
- **Описание**: Начать голосование за исключение игрока из игры (требуется активная игра с минимум 3 игроками)
- **Использование**: `/votekick`
- **Ответ**: Сообщение с голосованием за исключение или сообщение об ошибке

## Inline кнопки

### Кнопки в сообщении /start
- **🎮 Играть!**: Создает новую игровую сессию для чата или присоединяется к существующей активной игре в чате. Первый нажавший создает игру, последующие присоединяются.
- **📋 Правила игры**: Показывает подробные правила игры
- **❓ Помощь**: Показывает список команд и справку (эквивалентно /help)

### Кнопки в комнате ожидания
- **🎮 Присоединиться к игре**: Присоединяется к игре в комнате ожидания
- **📋 Правила игры**: Показывает подробные правила игры
- **❓ Помощь**: Показывает список команд и справку
- **🚀 Начать игру**: Начинает игру (только для создателя)

### Кнопки в игре
- **🎲 Бросить кубик**: Бросает 1 кубик и перемещает игрока
- **🎲 Бросить кубик** (благотворительность): Бросает 1 кубик или 2 кубика (выбор)

### Кнопки голосования за окончание игры
- **🛑 Завершить игру**: Голосует за окончание игры

### Кнопки профиля игрока
- **👤 Профиль**: Показывает подробную информацию об игроке с кнопками для просмотра активов и кредитов
- **📊 Статистика**: Показывает статистику всех игроков в игре
- **🏠 Активы**: Показывает список всех активов игрока
- **💳 Кредиты**: Показывает информацию о кредитах игрока

### Кнопки сделок
- **💼 Купить**: Покупает текущую сделку наличными
- **💳 Купить кредиткой**: Покупает сделку с использованием кредитной карты (2% от стоимости)
- **➕ Добавить 1**: Увеличивает количество акций на 1 (для unlimited stocks)
- **➖ Убрать 1**: Уменьшает количество акций на 1 (для unlimited stocks)
- **➕10 Добавить 10**: Увеличивает количество акций на 10 (для unlimited stocks)
- **➖10 Убрать 10**: Уменьшает количество акций на 10 (для unlimited stocks)
- **💰 Продать акции**: Продает акции по текущей цене
- **💸 Оплатить расходы**: Оплачивает расходы по сделке (требует недвижимости)
- **👥 Предложить другому**: Предлагает сделку другому игроку с комиссией (для сделок с canSellToOthers)
- **⏭️ Пропустить**: Пропускает текущую сделку
- **1%**, **3%**, **5%**, **10%**, **15%**, **20%**: Выбор комиссии при предложении сделки

### Кнопки miscellaneous карт
- **💰 Оплатить [сумма] ₽**: Оплачивает miscellaneous карту наличными
- **💳 Кредитная карта**: Оплачивает miscellaneous карту кредиткой (для карт с credit: true)
- **⏭️ Пропустить**: Пропускает miscellaneous карту

### Кнопки поля благотворительности
- **🙏 Пожертвовать 10% дохода**: Пожертвовать 10% дохода и получить бонус на 3 хода
- **⏭️ Пропустить**: Пропустить благотворительность

### Кнопки поля безработицы
- **💰 Оплатить расходы**: Оплачивает общие расходы наличными
- **💳 Кредитная карта**: Оплачивает общие расходы кредиткой

### Кнопки поля "Рынок"
- **🏠 Продать [актив] за [цена] ₽**: Продает актив по market цене
- **⏭️ Пропустить**: Пропускает market событие

### Кнопки банкротства
- **🏠 Активы**: Показывает активы для продажи в банкротстве
- **💳 Кредиты**: Показывает кредиты для оплаты в банкротстве
- **🏠 Продать [актив] за [цена] ₽**: Продает актив за половину стоимости
- **💰 Оплатить [кредит] за [сумма] ₽**: Оплачивает ежемесячный платеж по кредиту
- **⬅️ Назад / ➡️ Вперед**: Навигация по страницам активов/кредитов
