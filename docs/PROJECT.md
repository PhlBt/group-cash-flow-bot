# Проект CashFlow Telegram Bot

## Описание

CashFlow Telegram Bot - это приложение для игры в настольную игру CashFlow через Telegram. Бот позволяет пользователям создавать игровые сессии, присоединяться к существующим играм и взаимодействовать с игровым процессом.

## Архитектура приложения

Приложение построено по принципу разделения ответственности с использованием паттерна сервисов:

- **DatabaseService**: Управляет подключением к MongoDB и содержит всю логику работы с базой данных
- **GameService**: Бизнес-логика игры, фасад для операций с играми (делегирует вызовы DatabaseService)
- **MessageService**: Формирование и отправка сообщений пользователям
- **Handlers**: Обработка команд Telegram, координация между сервисами
