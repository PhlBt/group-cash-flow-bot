# CashFlow Telegram Bot - Полное описание проекта

## Общее описание

CashFlow - это Telegram бот для игры в образовательную финансовую игру "CashFlow" от Роберта Кийосаки. Игра учит финансовой грамотности, управлению деньгами и инвестициям. Цель игры - выйти из "крысиных бегов" путем накопления пассивного дохода, превышающего расходы.

### Архитектура проекта

- **bot.js** - основной файл бота, обработка команд и сообщений
- **game.js** - логика игры, класс CashFlowGame
- **player.js** - класс игрока Player
- **cards.js** - генерация игровых карт
- **professions.js** - профессии игроков
- **package.json** - зависимости и скрипты

**Правила игры (/rules):**
```
📚 ПРАВИЛА ИГРЫ CASHFLOW

🎯 ЦЕЛЬ ИГРЫ:
Выйти из "крысиных бегов", накопив пассивный доход, который превышает ваши расходы.

📋 ОСНОВНЫЕ ПРАВИЛА:

1️⃣ НАЧАЛО ИГРЫ
• Используйте /join для присоединения к игре
• После присоединения всех игроков используйте /startgame
• Каждый игрок получает случайную профессию с зарплатой, расходами и начальными сбережениями

2️⃣ ХОД ИГРЫ
• Игроки ходят по очереди
• Бросьте кубик командой /roll
• В зависимости от клетки, на которую вы попали, происходят разные события

3️⃣ ТИПЫ КЛЕТОК:
• 🎯 МАЛАЯ СДЕЛКА - небольшие инвестиции (акции, квартиры)
• 💼 БОЛЬШАЯ СДЕЛКА - крупные инвестиции (бизнес, недвижимость)
• 📈 РЫНОК - события рынка (рост/падение цен, бонусы)
• 🎁 ВОЗМОЖНОСТЬ - специальные возможности
• 💸 РАСХОДЫ - непредвиденные траты (обязательны к оплате)
• 💰 ДЕНЬ ЗАРПЛАТЫ - получение зарплаты и расчет месячного баланса

4️⃣ МЕСЯЧНЫЙ БАЛАНС
В конце каждого месяца (при прохождении полного круга или попадании на день зарплаты):
• ➕ Вы получаете зарплату
• ➕ Вы получаете пассивный доход от всех активов
• ➖ Вы оплачиваете все расходы (базовые + от пассивов)

5️⃣ АКТИВЫ И ПАССИВНЫЙ ДОХОД
• Активы приносят пассивный доход каждый месяц
• Пассивный доход добавляется к вашему балансу автоматически
• Активы можно покупать за наличные или с помощью кредита

6️⃣ КРЕДИТОВАНИЕ
• Если у вас недостаточно денег для покупки актива, можно взять кредит
• Процентная ставка: 1% в месяц (≈12% годовых)
• Ежемесячные платежи по кредитам автоматически вычитаются из баланса
• Кредиты можно погасить досрочно командой /payloan

7️⃣ ДЕНЕЖНЫЙ ПОТОК
• Денежный поток = Общий доход - Общие расходы
• Общий доход = Зарплата + Пассивный доход
• Общие расходы = Базовые расходы + Платежи по кредитам + Расходы от пассивов

8️⃣ ПОБЕДА
🎉 Вы выходите из "крысиных бегов", когда:
   Пассивный доход > Общие расходы

💡 СТРАТЕГИЯ:
• Покупайте активы, которые приносят пассивный доход
• Управляйте кредитами разумно
• Стремитесь увеличить пассивный доход быстрее, чем растут расходы
• Используйте возможности рынка для увеличения дохода

📊 КОМАНДЫ:
• /status - посмотреть статус всех игроков
• /myinfo - ваша детальная информация
• /loans - ваши кредиты
• /help - справка по командам
```

## Карточки игры

### Малые сделки (Small Deals)

Генерируются функцией `generateSmallDeal()` из массива:

1. **Акции**
   - Стоимость: 1000-6000$
   - Доход: 50-250$/месяц
   - Первый взнос: 30% стоимости

2. **Однокомнатная квартира**
   - Стоимость: 20000-70000$
   - Доход: 100-600$/месяц
   - Первый взнос: 30% стоимости

3. **Бизнес**
   - Стоимость: 10000-40000$
   - Доход: 150-550$/месяц
   - Первый взнос: 30% стоимости

4. **Облигации**
   - Стоимость: 2000-12000$
   - Доход: 30-180$/месяц
   - Первый взнос: 30% стоимости

### Большие сделки (Big Deals)

Генерируются функцией `generateBigDeal()` из массива:

1. **Многоквартирный дом**
   - Стоимость: 100000-300000$
   - Доход: 500-2500$/месяц
   - Первый взнос: 30% стоимости

2. **Крупный бизнес**
   - Стоимость: 80000-230000$
   - Доход: 400-1900$/месяц
   - Первый взнос: 30% стоимости

3. **Торговый центр**
   - Стоимость: 200000-500000$
   - Доход: 1000-4000$/месяц
   - Первый взнос: 30% стоимости

### Карты рынка (Market Cards)

Генерируются функцией `generateMarketCard()` из массива:

1. **Рынок недвижимости растет**
   - Эффект: `double_real_estate`
   - Удваивает стоимость всей недвижимости игрока

2. **Рынок недвижимости падает**
   - Эффект: `half_real_estate`
   - Уменьшает стоимость всей недвижимости вдвое

3. **Рынок акций падает**
   - Эффект: `halve_stocks`
   - Уменьшает стоимость всех акций и облигаций вдвое

4. **Рынок акций растет**
   - Эффект: `double_stocks`
   - Удваивает стоимость всех акций и облигаций

5. **Инфляция**
   - Эффект: `increase_expenses`
   - Увеличивает все расходы игрока на 10%

6. **Экономический рост**
   - Эффект: `increase_income`
   - Увеличивает зарплату и пассивный доход на 10%

7. **Бонус**
   - Эффект: `salary_bonus`
   - Игрок получает бонус в размере месячной зарплаты

### Карты возможностей (Opportunity Cards)

Генерируются функцией `generateOpportunityCard()` из массива:

1. **Случайная сделка**
   - Эффект: `random_deal`
   - Игрок получает случайную малую или большую сделку

2. **Дополнительный ход**
   - Эффект: `extra_turn`
   - Игрок может бросить кубик еще раз

3. **Налоговый вычет**
   - Эффект: `tax_refund`
   - Игрок получает 1000$

### Карты расходов (Doodad Cards)

Генерируются функцией `generateDoodadCard()` из массива:

1. **Покупка автомобиля**
   - Стоимость: 5000-15000$

2. **Отпуск**
   - Стоимость: 2000-7000$

3. **Ремонт**
   - Стоимость: 3000-11000$

4. **Подарок**
   - Стоимость: 1000-4000$

## Логика игры

### Класс Player

**Свойства:**
- `userId` - ID пользователя в Telegram
- `username` - имя пользователя
- `profession` - объект профессии
- `salary` - месячная зарплата
- `expenses` - базовые месячные расходы
- `cash` - текущий баланс наличных
- `passiveIncome` - пассивный доход от активов
- `totalIncome` - общий доход (зарплата + пассивный)
- `totalExpenses` - общие расходы (базовые + платежи по кредитам)
- `cashFlow` - денежный поток (totalIncome - totalExpenses)
- `assets` - массив активов
- `liabilities` - массив пассивов
- `loans` - массив кредитов
- `position` - позиция на игровом поле (0-23)
- `inFastTrack` - флаг нахождения на Fast Track

**Методы:**

#### Управление активами
- `addAsset(asset)` - добавляет актив, обновляет passiveIncome
- `removeAsset(assetId)` - удаляет актив, обновляет passiveIncome

#### Управление пассивами
- `addLiability(liability)` - добавляет пассив, обновляет totalExpenses
- `removeLiability(liabilityId)` - удаляет пассив, обновляет totalExpenses

#### Финансовые операции
- `pay(amount)` - списывает деньги с баланса
- `receive(amount)` - добавляет деньги на баланс

#### Кредитование
- `takeLoan(amount, assetTitle)` - берет кредит (1% месячных от суммы)
- `payLoan(loanId, amount)` - погашает кредит полностью или частично

#### Месячный баланс
- `processMonthEnd()` - рассчитывает конец месяца:
  - Начисляет зарплату
  - Начисляет пассивный доход
  - Списывает все расходы
  - Возвращает детали расчета

#### Fast Track
- `canEscapeRatRace()` - проверка условия выхода (passiveIncome >= totalExpenses)
- `enterFastTrack()` - переход на Fast Track
- `checkWin()` - проверка победы на Fast Track

#### Банкротство
- `checkBankruptcy()` - проверка условий банкротства:
  - cash <= 0 и cashFlow < 0 (обычная игра)
  - fastTrackCash < 0 (Fast Track)

### Процесс игры

1. **Подготовка:**
   - Игроки присоединяются командой `/join`
   - Каждый получает случайную профессию
   - Один игрок запускает игру `/startgame`

2. **Игровой цикл:**
   - Игроки ходят по очереди
   - Текущий игрок бросает кубик `/roll`
   - В зависимости от клетки происходит событие
   - Игрок принимает решение (купить/пропустить/оплатить)
   - Переход хода к следующему игроку

3. **Конец месяца:**
   - При прохождении полного круга или попадании на "День зарплаты"
   - Начисление зарплаты и пассивного дохода
   - Списание расходов
   - Проверка на выход из крысиных бегов

4. **Fast Track:**
   - При выполнении условия passiveIncome >= totalExpenses
   - Новая фаза игры с повышенными ставками
   - Цель: накопить капитал для "мечты" (passiveIncome * 100 + 50000)

5. **Завершение:**
   - Победа: достижение мечты на Fast Track
   - Поражение: банкротство или исключение

### Финансовая система

**Денежный поток:**
```
Денежный поток = (Зарплата + Пассивный доход) - (Базовые расходы + Платежи по кредитам + Расходы от пассивов)
```

**Условие победы:**
```
Пассивный доход >= Общие расходы
```

**Кредитование:**
- Ставка: 1% в месяц (≈12% годовых)
- Первый взнос: 30% стоимости актива
- Кредит на остаток стоимости

**Продажа активов:**
- Цена продажи: 80% от стоимости актива
- Потеря пассивного дохода от проданного актива

## Особенности и механики

### Синхронизация сообщений
- Используется `MessageQueue` для последовательной отправки сообщений в чате
- Предотвращает путаницу в порядке сообщений

### Обработка ошибок
- Все сетевые операции обернуты в try-catch
- При ошибках отправки сообщения продолжается очередь

### Баланс игры
- Стоимость активов растет с уровнем (малые/большие сделки)
- Доход от активов пропорционален стоимости
- Кредиты доступны, но с высокими процентами
- Риск банкротства при неправильном управлении

### Масштабируемость
- Поддержка нескольких игроков в одном чате
- Независимые игры в разных чатах
- Возможность голосования за исключение игроков

### Образовательный аспект
- Реалистичные финансовые расчеты
- Понятия пассивного дохода, денежного потока
- Стратегия управления долгами и активами
- Понимание рисков инвестиций
