# CashFlow Telegram Bot

Телеграм-бот для игры в CashFlow - образовательную игру о финансовой грамотности от Роберта Кийосаки.

## Описание

Этот бот позволяет играть в CashFlow прямо в Telegram. Цель игры - выйти из "крысиных бегов", накопив пассивный доход, превышающий ваши расходы.

## Установка

1. Клонируйте репозиторий или скачайте файлы
2. Установите зависимости:
```bash
npm install
```

3. Получите токен бота от [@BotFather](https://t.me/BotFather) в Telegram:
   - Напишите `/newbot` в чат с BotFather
   - Следуйте инструкциям для создания бота
   - Скопируйте полученный токен

4. Запустите бота:
```bash
BOT_TOKEN=ваш_токен_бота node bot.js
```

Или создайте файл `.env`:
```
BOT_TOKEN=ваш_токен_бота
```

И используйте пакет `dotenv` для загрузки переменных окружения.

## Использование

### Команды бота:

- `/start` - Начать работу с ботом и увидеть список команд
- `/join` - Присоединиться к игре
- `/startgame` - Начать игру (после того как все присоединились)
- `/roll` - Бросить кубик (ваш ход)
- `/buy` - Купить актив из текущей сделки
- `/skip` - Пропустить сделку
- `/pay` - Оплатить расход (doodad карта)
- `/market` - Применить эффект карты рынка
- `/opportunity` - Применить возможность
- `/status` - Посмотреть статус всех игроков
- `/myinfo` - Ваша детальная информация
- `/help` - Справка по командам
- `/endgame` - Завершить игру

### Как играть:

1. Все игроки используют команду `/join` для присоединения к игре
2. Один из игроков запускает игру командой `/startgame`
3. Игроки по очереди бросают кубик командой `/roll`
4. В зависимости от клетки, на которую попали, появляются разные карты:
   - **Малая сделка** - небольшие инвестиции (акции, квартиры)
   - **Большая сделка** - крупные инвестиции (бизнес, недвижимость)
   - **Рынок** - события рынка (рост/падение цен)
   - **Возможность** - специальные возможности
   - **Расходы** - непредвиденные траты
   - **День зарплаты** - получение зарплаты

5. Цель: накопить пассивный доход больше ваших расходов!
