# CashFlow Telegram Bot

Телеграм-бот для игры в CashFlow - образовательную игру о финансовой грамотности от Роберта Кийосаки.

## Описание

Этот бот позволяет играть в CashFlow прямо в Telegram. Цель игры - выйти из "крысиных бегов", накопив пассивный доход, превышающий ваши расходы.

**Все суммы в игре указаны в рублях (₽).**

## Установка

### Вариант 1: Локальная установка

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd cashFlow
```

2. **Установите зависимости:**
```bash
npm install
```

3. **Настройте переменные окружения:**
```bash
cp .env.example .env
```

Отредактируйте `.env` файл:
```env
BOT_TOKEN=your_bot_token_here
MONGODB_URL=mongodb+srv://username:password@cluster.mongodb.net/cashflow
NODE_ENV=development
```

4. **Запустите бота:**
```bash
# Для разработки
npm run dev

# Для продакшена
npm start
```

### Вариант 2: Docker (рекомендуется)

1. **Клонируйте репозиторий:**
```bash
git clone <repository-url>
cd cashFlow
```

2. **Настройте переменные окружения:**
```bash
cp .env.example .env
# Отредактируйте BOT_TOKEN и MONGODB_URL в .env файле
```

3. **Запустите с Docker Compose:**
```bash
docker-compose up -d
```

Это запустит бота в контейнере. MongoDB должна быть доступна через облачный провайдер.

## Использование

### Команды бота:

#### 🎮 Основные команды игры:
- `/start` - Начать работу с ботом и увидеть список команд
- `/join` - Присоединиться к игре
- `/startgame` - Начать игру (после того как все присоединились)
- `/roll` - Бросить кубик (ваш ход)
- `/buy` - Купить актив из текущей сделки
- `/skip` - Пропустить сделку
- `/pay` - Оплатить расход (doodad карта)
- `/market` - Применить эффект карты рынка
- `/opportunity` - Применить возможность
- `/status` - Посмотреть статус всех игроков
- `/myinfo` - Ваша детальная информация
- `/endgame` - Завершить игру

#### 💰 Финансовые команды:
- `/loans` - Посмотреть ваши кредиты
- `/payloan` - Погасить кредит
- `/sellasset` - Продать актив

#### 📊 Статистика:
- `/mystats` - Ваша личная статистика
- `/leaderboard` - Топ игроков
- `/leaderboard wins` - Топ по победам
- `/leaderboard cash` - Топ по денежному потоку
- `/leaderboard games` - Топ по количеству игр

**⚠️ Примечание:** Только игры с 2+ игроками учитываются в статистике и рейтингах.

#### 📚 Дополнительно:
- `/rules` - Правила игры
- `/votekick` - Голосование за исключение игрока
- `/help` - Справка по командам

### Как играть:

1. Все игроки используют команду `/join` для присоединения к игре
2. Один из игроков запускает игру командой `/startgame`
3. Игроки по очереди бросают кубик командой `/roll`
4. В зависимости от клетки, на которую попали, появляются разные карты:
   - **Малая сделка** - небольшие инвестиции (акции, квартиры)
   - **Большая сделка** - крупные инвестиции (бизнес, недвижимость)
   - **Рынок** - события рынка (рост/падение цен)
   - **Возможность** - специальные возможности
   - **Расходы** - непредвиденные траты
   - **День зарплаты** - получение зарплаты + пассивный доход - расходы (денежный поток)

5. Цель: накопить пассивный доход больше ваших расходов!

## Особенности

- ✅ Поддержка нескольких игроков в одном чате

- ✅ Система карт (сделки, рынок, возможности)

- ✅ Расчет денежного потока
