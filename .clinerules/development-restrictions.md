## Brief overview
Правила ограничения разработки для проекта Cash Flow Telegram бота. Определяет, что Cline не должен делать без явной команды пользователя.

## Documentation restrictions
- Не создавать новые документы (README.md, .md файлы) без прямой команды
- Не обновлять существующую документацию без прямой команды
- Не генерировать автоматическую документацию к коду
- Не создавать комментарии в коде для документирования

## Testing restrictions
- Не писать unit-тесты, интеграционные тесты или любые другие тесты
- Не запускать существующие тесты без прямой команды
- Не создавать тестовые файлы или тестовые директории
- Не использовать testing frameworks без явной просьбы

## Development workflow
- Ожидать четких инструкций для всех действий
- Не предпринимать инициативу в создании документации или тестов
- Сосредоточиться только на основной функциональности по запросу пользователя
- Задавать уточняющие вопросы при неоднозначных требованиях
